# Dependencies

This page lists the main third-party components used by MILES Wear OS and what each
one is for. See [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) for
attribution.

- **Kotlin** — application language
- **Jetpack Compose for Wear OS** — UI
- **AndroidX** — platform libraries
- **OpenStreetMap / OSRM** — maps and offline routing
