**MILES Wear OS** brings the MILES activity-tracking experience to your wrist, with a dedicated watch app kept separate from the main Android repository.

## ✨ Features

- ⌚ Wear OS activity tracking
- ❤️ Heart-rate and sensor support
- 🏃 Workout controls
- 📍 GPS tracking
- 📱 Phone ↔ watch syncing
- 🔒 Privacy-focused design
- ⚡ Built for quick, efficient watch use

## 📱 Main MILES Project

The Android app lives in its own repository:

**MILES Android → https://github.com/anshlabs716/miles**

The two projects are intentionally separate while working together as the MILES ecosystem.

## 🛠️ Technology

- Kotlin
- Jetpack Compose for Wear OS
- Wear OS APIs
- Android Health & sensor APIs
- Wearable Data Layer

## 📦 Build

Requirements: **JDK 17, Android SDK, Git**

```bash
git clone https://github.com/anshlabs716/miles-wearos.git
cd miles-wearos
chmod +x gradlew
./gradlew assembleDebug
```
